# 企业微信智能表格：已核实的事实

核实时间 2026-09，来源为企微官方帮助中心与官方渠道。
**界面随版本变化——若发现与用户屏幕不符，以用户实际看到的为准，并当场修正你的说法。**

---

## 入口路径【确定】

- **电脑端**：`文档 → 新建表格 → 智能表格`；或 `左侧栏 → 智能文档 → 新建智能表格`
- **手机端**：`文档 → 右上角「+」→ 智能表格`
- 两端路径**不同**，不要混用

⚠️ 网上流传很广的「工作台 → 智能表格」**官方从未提过**，别用这个说法。

---

## 模板【确定，但名称不确定】

- 创建智能表格时会让你选模板，模板自带仪表盘和多个视图
- 官方点过名的模板：项目管理表、订单管理表、库存管理表、**工单管理表**
- 但官方帮助中心的模板清单里**没有「工单管理」**，只有「客户服务与销售跟进」等
- **没有叫「模板中心」的独立入口**——模板就是在新建的时候选的，找不到是正常的

**措辞建议**：「创建时在模板列表里挑一个最接近的；没有合适的就用空白表，后面自己加列，效果一样。」

---

## 字段编辑【确定】

- **加字段**：滑到表格最右侧点「+」→ 输入列名称 → 选列类型 → 确认
- **改类型**：点列头「▼」进列设置面板，或右键列头 →「设置列类型」
- 列类型 20 余种，常用的：文本、选项（单选/多选）、数字、日期、图片、文件、
  成员、群聊、关联、链接、公式、查找引用、自动编号、创建人
- 限制：图片每格最多 9 张、单张 20MB；**文件在手机端不能上传**

全程点选即可，不需要公式或代码——这正是不懂技术的用户能自助的原因。

---

## 自动化【触发确定；动作清单存疑，别背】

- 官方名称：**「自动化流程」**，位置在智能表格**右上角** →「+空白流程」
  （部分版本界面显示为「自动化」）
- **触发条件 4 类**：
  | 触发 | 用途 |
  |---|---|
  | 添加新记录时 | 新工单自动通知 |
  | 记录内容变更时 | 状态变更时联动 |
  | 定时重复（日/周/月/工作日 + 指定时间） | 每天汇总 |
  | **到达记录中的时间时** | **超期预警靠它** |

  「到达记录中的时间时」支持提前 `2小时 / 1小时 / 45分 / 30分 / 15分 / 5分 / 立即` 触发。
  限制：单表最多 100 个此类流程。

⚠️ **执行动作的清单各版本不一致，绝对不要凭记忆背。**

- 官方正文列了：发送消息、新增记录、修改记录、查找记录
- 同一官方页面另一节又提到：「发起群聊」「发送到群聊」
- 第三方最全的清单列了 7 项

**关键问题：「创建待办」在所有已知清单里都没有出现。**
但这是「未列出」，不是官方明确否认——也可能是新功能没进文档。

→ **所以配的时候，让用户当场看一眼动作列表再决定**：

| 实际看到什么 | 怎么办 |
|---|---|
| 有「创建待办 / 添加到待办」 | **用它** —— 待办会一直挂在责任人列表里，最不容易漏 |
| 没有，但有「发送消息」 | 发给指定同事，**一对一发**，不要发群 |
| 都没有 | 让用户把动作列表念给你听，挑最接近的，并如实告诉他这样做的损失 |

必须让他知道的两件事：
- **群消息不支持 @成员**，且容易被淹没
- 免费版自动化流程**每人每月 100 次**，规则别设太频繁

## ⚠️ 「群机器人」已经改名叫「消息推送」【确定】

**v4.1.41 起更名**，界面里已经找不到「群机器人」三个字。

- 路径：`内部群聊 → 右上角三个点 → 消息推送 → 添加`
- 取 Webhook：`群聊 → 右上角「…」→ 消息推送 → 点对应项 → Webhook 地址`
- **单向**：只能主动推，不能接收消息
- 限制：**仅内部群**（外部群不行）；20 条/分钟；**不支持 @成员**；群开启全员禁言会推不出去

**主动告诉用户这件事**——否则他会在群里翻半天找不到「群机器人」，然后怀疑自己。

## 仪表盘与多视图【确定】

- **仪表盘**：智能表格**左下角「+」→「新建仪表盘」→「添加图表」**
- 图表类型：柱状图、饼图、折线图、数字卡
- **多视图**：表头点「+」→「新建视图」→ 选类型
- 视图类型：表格、看板、甘特、画册、日历、表单
- ⚠️ **看板视图的分组依据只能是「单选」列或未开启多选的「人员」列**
  → 所以字段设计时，「状态」设成单选、「责任人」设成成员，看板才建得出来

## 容量与收费【确定】

- 智能表格**免费**
- 免费版边界：文档容量 **1GB**；**自动化流程每人每月 100 次**
- 付费「文档高级功能」**¥200/人/年** → 容量无限 + 自动化 10000 次/月/人
- 硬上限（免费付费相同）：单工作表 10 万行 / 150 列；单文件最多 256 个工作表

## 两个会让用户翻车的坑

1. **由「在线表格」转成的智能表格没有仪表盘。**
   官方解法：右上角「内容权限」→「生成智能表格副本」，新副本里才有。
   → 所以一开始就用「新建 → 智能表格」，别用现成表格转换。

2. **智能表格不能打印、也导不出 PDF。**
   只能导出为 Excel（右上角「≡」→ 导出为 .xlsx 或 Excel+附件 .zip）。
   用户如果打算打印或发给客户，早点告诉他，别等他用的时候才发现。
